# Шаблон модуля (для пользователя)

**Шаблон модуля** — учебный раздел ERGO MS. В нём показаны типовые экраны, которые встречаются в других модулях системы.

## Что можно открыть

- **Главная** — обзор возможностей шаблона.
- **Статус** — проверка работоспособности раздела.
- **Паттерны** — примеры элементов интерфейса (списки, формы, таблицы), как в рабочих модулях.

Пункты появляются в меню только если модуль установлен и вашей роли выдан доступ.

## Зачем это обычному пользователю

Если администратор открыл вам шаблон — используйте его как песочницу: посмотрите, как устроены типовые страницы, прежде чем работать в боевых разделах. Данные в шаблоне учебные и не влияют на остальные модули.
